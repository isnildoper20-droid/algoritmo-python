# Algoritmo A* y Teoría de Juegos en Python

## Descripción

Este proyecto muestra la implementación del algoritmo A* en Python, el uso de heurísticas y ejemplos de teoría de juegos.

## Contenido del proyecto

- Algoritmo A*
- Heurísticas
- Teoría de juegos
- Ejemplos en Python

## Archivos

astar.py -> Implementación del algoritmo A*

heuristica.py -> Ejemplos de heurísticas

teoria_juegos.py -> Ejemplos de teoría de juegos

main.py -> Ejecuta todo el proyecto

## Ejecución

Ejecutar el archivo:

python main.py

## Tecnologías

Python 3
